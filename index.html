📲 Comment installer un fichier GPX sur votre appli ?

📱 Kurviger (recommandé)
  1. Télécharger le fichier GPX
  2. Ouvrir Kurviger
  3. Menu → Importer → sélectionner le fichier
  4. Lancer la navigation
📱 Google Maps
  1. Télécharger le fichier GPX
  2. Ouvrir Google Maps sur PC
  3. Menu → Vos trajets → Importer
  4. Partager vers votre téléphone
🗺️ GPS Garmin / TomTom
  1. Télécharger le fichier GPX
  2. Connecter le GPS en USB
  3. Copier dans le dossier GPX
  4. Éjecter et lancer sur le GPS
📱 Maps.me / OsmAnd
  1. Télécharger le fichier GPX
  2. Ouvrir le fichier depuis les téléchargements
  3. Choisir "Ouvrir avec Maps.me"
  4. Le tracé s'importe automatiquement
